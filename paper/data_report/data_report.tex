\subsection{数据相关性分析}

Pearson 相关系数定义为

\begin{equation}
    r_{XY}
    =
    \frac{\operatorname{cov}(X,Y)}
    {\sigma_X\sigma_Y}.
    \label{eq:pearson}
\end{equation}

由式~\ref{eq:pearson} 计算各变量之间的线性相关关系，其结果如图~\ref{fig:corr} 所示。
